# Jarvis OS v1 — Developer Guide

## Architecture Principles

1. **Event-Driven** — All components communicate via Event Bus, no direct coupling
2. **Service Registry** — Dependencies injected via registry, no globals
3. **Thread Safety** — UI thread never blocks; heavy work goes to Task Queue or QThread
4. **Offline-First** — All AI inference runs locally (Ollama, Whisper, Piper)
5. **Versioned API** — All endpoints under `/api/v1/`, backward-compat redirects

## Adding a New Feature

### 1. Create a Tool Plugin
```python
# plugins/my_tool/__init__.py
TOOL = {
    "name": "my_tool",
    "description": "Does something useful",
    "usage": "my_tool <args>",
}

def run(args: str = "") -> str:
    return f"Result: {args}"
```

### 2. Add an API Route
```python
# network/routes/my_route.py
from fastapi import APIRouter

router = APIRouter(prefix="/api/v1/my-feature", tags=["my-feature"])

@router.get("/")
async def my_endpoint():
    return {"status": "ok"}
```

Register in `network/api/server.py`:
```python
from network.routes.my_route import router as my_router
app.include_router(my_router)
```

### 3. Add a GUI Page
```python
# desktop/pages/my_page.py
from PySide6.QtWidgets import QWidget, QVBoxLayout, QLabel

class MyPage(QWidget):
    def __init__(self):
        super().__init__()
        layout = QVBoxLayout(self)
        layout.addWidget(QLabel("My Page"))

    def refresh(self):
        pass
```

Add to `desktop/window.py` sidebar.

### 4. Subscribe to Events
```python
from core.event_bus import bus

def on_wake_word(data):
    print(f"Wake word detected: {data}")

bus.subscribe("WakeWordDetected", on_wake_word)
```

### 5. Submit Background Tasks
```python
from core.task_queue import task_queue

def long_operation():
    # heavy work
    pass

task_queue.submit("my_task", long_operation)
```

## Event Bus Events

| Event | Published By | Data |
|------|-------------|------|
| `ApplicationStarted` | bootstrap | `{"services": [...]}` |
| `ApplicationStopped` | bootstrap | `None` |
| `WakeWordDetected` | assistant_service | `{"score": 0.8}` |
| `SpeechFinished` | assistant_service | `{"text": "..."}` |
| `LLMResponse` | assistant_service | `{"response": "..."}` |
| `ToolExecuted` | router | `{"tool": "...", "result": "..."}` |
| `HealthCheckFailed` | health_manager | `{"service": "..."}` |
| `HealthCheckPassed` | health_manager | `{"service": "..."}` |
| `TaskStarted` | task_queue | `{"name": "..."}` |
| `TaskCompleted` | task_queue | `{"name": "..."}` |
| `TaskFailed` | task_queue | `{"name": "...", "error": "..."}` |
| `Automation*` | automation_engine | Various |

| `tts` | TextToSpeech | Piper TTS |

| `automation_engine` | AutomationEngine | Automation |
| `event_store` | EventStore | Event persistence |
| `metrics` | MetricsEngine | Performance metrics |
| `telemetry` | TelemetryCollector | Telemetry |
| `recovery_engine` | RecoveryEngine | Auto-recovery |
| `flag_manager` | FeatureFlagManager | Feature flags |

## Feature Flags

Defined in `flags/flags.json`:
```json
{
    "browser_v1": false,
    "automation_v1": true,
    "metrics": true
}
```

Toggle at runtime:
```python
from flags import flag_manager
if flag_manager.is_enabled("browser_v1"):
    # feature code
```

python -m pytest tests/ -v

## Building

```bash
python -m PyInstaller --name Jarvis --windowed --onefile app/bootstrap.py
```

Use InnoSetup with the `.iss` script generated by `release_manager.create_installer_script()`.
